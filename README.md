## 🌿 About Sri Kuzhali Traders

Founded in **2008 in Erode**, Tamil Nadu—the heartland of South India's premier coconut belt along the fertile Kaveri basin—**Sri Kuzhali Traders** bridges generational agrarian traditions with modern wholesale supply chain logistics. 

We procure freshly harvested, mature coconuts directly from local farm gates, calibrate them through rigorous sizing and sorting rings, dry high-oil copra in dedicated kilns, and dispatch bulk consignments across North Indian oil mills, wholesale terminal mandis, and retail distributors.

This digital platform serves as the interactive bridge between **Tamil Nadu farmers**, **pan-Indian commodity buyers**, and **food enthusiasts** seeking transparency, scientific grading standards, and agricultural heritage.

## ✨ Key Features & Experience Modules

### 1. 🔄 Complete Coconut Life Cycle Roadmap (`#lifecycle`)
An interactive, educational story map tracking the full arc of the revered *Kalpavriksha* (the tree of life):
- **01 — The Beginning (Seed to Sapling)**: Mature mother seed selection, nursery bedding, and initial sprout development.
- **02 — Growing Toward the Sky (3–10 Years)**: Dwarf cultivars (3–4 years bearing) vs. Tall varieties (6–10 years), root depth, and canopy health.
- **03 — Flowering, Fruiting & Harvest (Fruit Development)**: Inflorescence, tender nut water phase, and peak 11–12 month copra harvesting.
- **04 — From Coconut to Golden Oil (Processing Pipeline)**: Interactive 5-step animated diagram showing Dehusking → Splitting → Copra Kiln Drying (<6% moisture) → Expeller Pressing → Micro-Filtration, along with a deep-dive comparison into Virgin Coconut Oil (VCO).
- **05 — A Place in Every Kitchen (Everyday Life)**: Culinary applications from cold-pressed cooking oil, coconut milk, and chutneys to sacred temple prasad.
- **06 — Nothing Goes to Waste (The Second Life)**: 100% zero-waste circular matrix highlighting coir rope, horticulture coco peat, shell activated carbon, eco-cutlery, and sweet germinated haustorium (*பொங்கு*).
- **Dual Display Modes**: Toggle seamlessly between an **Interactive Stepper** and a **Full Journey Vertical Roadmap**.

### 2. 🌐 Native Bilingual Architecture (English & தமிழ்)
- Comprehensive instant language switching between English and Tamil.
- Typographic harmony using **Cormorant Garamond**, **Noto Serif Tamil**, and **Space Grotesk**.
- All trade terms, process steps, and specifications are meticulously translated with authentic agricultural Tamil terminology.

### 3. 📲 Direct WhatsApp Quotation & Lead Generator
- Instant structured message builder for both **Farmers looking to sell** and **Wholesale Buyers looking to purchase**.
- Auto-formats customer details, desired coconut grades (A-Grade 550g+, B-Grade, Kiln-Dried Copra), tonnage, target delivery dates, and dispatch hubs directly into WhatsApp click-to-chat links.

### 4. 🧠 "Did You Know?" Heritage & Science Spotlight (`#did-you-know`)
- Curated agricultural insights, historical trade routes from Chola voyages to modern Erode mandis, and nutritional chemistry (Lauric acid & MCTs).
- Interactive trivia challenge testing knowledge on coconut cultivation and copra drying parameters.

### 5. 🎨 Custom Brand Identity & Favicon Suite
- Official vector emblem with authentic palm and coconut illustrations.
- Multi-resolution favicon suite:
  - `favicon.svg`: Scalable vector icon with brand squircle.
  - `favicon.ico`: Standard multi-size binary icon (16x16, 32x32, 48x48).
  - `apple-touch-icon.png`: High-definition 180x180 icon for iOS home screens.
  - `favicon-32x32.png` & `favicon-16x16.png` for universal browser compatibility.
- Responsive navigation bar with integrated brand signature and sticky mobile drawer.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended, verified on v22)
- [npm](https://www.npmjs.com/) (v9.0.0 or higher)

### 1. Installation
Clone the repository and install all dependencies:
```bash
git clone <repository-url>
cd sri-kuzhali-traders
npm install
```

### 2. Development Server
Start the local Vite development server on port 3000:
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:3000`.

### 3. Production Build
Compile and bundle the production-ready application:
```bash
npm run build
```
The optimized bundle will be generated in the `dist/` directory.

### 4. Code Quality & Verification
To run TypeScript compilation and type checks:
```bash
npm run lint
```
